对战规则

公平竞技，严格执行淘汰与连胜机制

日赛规则

  • 1v1 单场无奖励，仅记录胜/败场
  • 单日累计败 3 场 → 当日禁赛
  • 连胜 3 场 → 强制下场回队尾
  • 连庄期间 不得换龙
  • 本周已获日冠军者 禁止再次参赛

周冠军赛规则

  • 仅限本周日冠军参加（2~6 人）
  • 单循环，每两人交手 1 场
  • 胜者 +1 分，败者 0 分，无平局
  • 同分：相互胜负 → 累计胜场 → 并列
  • 缺席者轮空不替补，对手自动获胜

日冠军判定

2 小时结束后统计总胜场，最高者为日冠军。同分时依次比较：胜率 → 总场次少者 → 并列。
