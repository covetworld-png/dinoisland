# 005-01 月巅峰充值榜 | 设计策略与实现要点

## 一、活动核心策略

### 1.1 商业目标
- **目标人群**: 大R玩家（鲸鱼用户）
- **核心目标**: 通过榜单竞争拉动单日充值峰值
- **获奖名额**: 仅1名，制造极致稀缺性

### 1.2 关键心理设计
| 设计点 | 策略意图 |
|--------|----------|
| **仅显示第一名金额，隐藏账号名** | 给第二名及追赶者制造"只差一点点"的压迫感，刺激追加充值 |
| **登录后显示个人排名+差距金额** | 让用户明确感知"离登顶还差多少"，降低决策模糊性 |
| **实时金额动态增长（模拟）** | 营造竞争激烈氛围，制造FOMO（错失恐惧） |
| **全服唯一特权+永久留名** | 强化社会认同与荣誉感，满足炫耀需求 |

### 1.3 规则要点
- **时间基准**: 越南时间 UTC+7，以充值订单"支付成功时间"为准
- **服务器范围**: Q服 + K服，同一账号跨服累计
- **充值渠道**: 仅统计官网直充，代充不计入
- **同额处理**: 金额相同时，以先达到该累计金额的支付时间戳判定（精确到毫秒）
- **顺延机制**: 第一名拒绝权益或账号异常时，顺延至第二名，以此类推

## 二、页面实现策略

### 2.1 三阶段视图架构（时间自动驱动）

页面三阶段状态**完全由硬编码的活动时间自动推进**，无需外部配置或服务端下发。

```javascript
// countdown.js 硬编码时间（越南时间 UTC+7）
const EVENT_START = new Date('2026-04-17T00:00:00+07:00').getTime();
const EVENT_END   = new Date('2026-04-17T23:59:59+07:00').getTime();
```

**自动流转逻辑**：
- `now < EVENT_START` → 活动前视图（预告阶段，榜单隐藏）
- `EVENT_START ≤ now < EVENT_END` → 活动中视图（开启榜单，显示剩余时间）
- `now ≥ EVENT_END` → 获胜公布视图（显示结果+名人殿堂）

**只要时间设置准确，页面会自动走完完整流程**：活动前 → 活动中 → 获胜公布，无需任何人工干预。

### 2.2 演示/测试按钮

为便于开发和运营演示，Header 提供两个手动切换按钮：

| 按钮 | 触发函数 | 作用 |
|------|----------|------|
| **切换倒计时** | `toggleCountdownMode()` | 在活动前 ↔ 活动中切换，同时控制榜单显隐 |
| **宣布获胜 / 查看活动** | `toggleResult()` | 在活动视图与获胜公布视图之间切换 |

**注意**：
- 手动点击后会设置 `window.countdownManualOverride = true`，停止自动时间判断覆盖当前状态
- 刷新页面后恢复自动时间判断
- **这两个按钮仅用于测试/演示，不应保留在正式生产环境**

### 2.3 双语切换策略
- **语言**: 越南语（默认）+ 中文
- **实现**: 所有双语文本使用 `<span class="lang-vi">` 和 `<span class="lang-cn">` 包裹，通过 `body[data-lang]` CSS 控制显隐
- **持久化**: 语言偏好存入 `localStorage.setItem('lang', ...)`，刷新后保持
- **标题同步**: 切换语言时同步更新 `document.title`

### 2.4 登录与榜单交互
```
未登录 → 显示"登录以实时更新您的充值金额" + 登录按钮
已登录 → 隐藏登录框，显示：当前排名、已充值金额、距离第一名差距
```

- **模拟实时竞争**: `setInterval` 每5秒在第一名金额上随机增加，动态刷新用户差距
- **榜首处理**: 若用户自身为第一名，隐藏"距离第1名还差"行

## 六、后续注意事项

1. **时间硬编码**: 当前活动时间为硬编码（2026-04-17），上线前需确认是否与运营排期一致
