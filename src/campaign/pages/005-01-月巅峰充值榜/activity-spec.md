# 「Long Vương Chiến - Vua Khủng Long」活动方案

## 一、活动概览

| 项目 | 内容 |
|------|------|
| 活动名称 | Long Vương Chiến - Vua Khủng Long（龙王之战 - 恐龙之王） |
| 活动类型 | 单日充值排行榜 |
| 目标人群 | 大R玩家（鲸鱼用户） |
| 核心目标 | 拉动充值 |

---

## 二、活动规则

### 2.1 时间规则

| 阶段 | 越南时间（UTC+7） | 北京时间 |
|------|------------------|----------|
| 活动进行 | 4月18日 00:00 - 23:59 | 4月18日 01:00 - 4月19日 00:59 |
| 权益生效 | 4月19日 08:00 - 4月20日 24:00 | 4月19日 09:00 - 4月21日 01:00 |

**时间判定标准：** 以充值订单的**支付时间**为准，按越南服务器时间（UTC+7）计算。

**权益生效时间说明：** 
- 权益生效每日08:00-24:00（越南时间），共2天
- GM服务时段视GM自动化工具开发进度确定

### 2.2 参与条件

- **服务器范围：** Q服 + K服
- **账号规则：** 两服使用同一账号，可分别充值，金额按**账号级累计**
- **充值渠道：** 仅统计**官网充值**，手动充值不计入

### 2.3 排名规则

| 规则项 | 说明 |
|--------|------|
| 获奖名额 | 1名（累计充值金额排名第一） |
| 金额相同处理 | 以**先达到该累计金额的支付时间戳**判定（精确到毫秒），先达者获胜 |
| 榜单展示 | 页面仅显示**第一名**的充值金额，以及**自己**的排名和金额（需登录） |
| 账号显示 | 活动期间**隐藏所有账号名**，活动结束后公布获奖名单时才显示 |
| 结果公布 | 活动结束后在活动页面公布获胜者 |

### 2.4 顺延机制

若第一名出现以下情况，获奖资格顺延至第二名，以此类推：
- 玩家拒绝接受权益
- 账号异常（被封禁/注销等）

## 三、活动流程

```
Day 0（4月17日）
├── 活动预告公告发布
└── 活动页面上线（榜单未开启）

Day 1（4月18日）- 活动日
├── 00:00 活动正式开始，榜单开启，实时更新
├── 全天玩家充值累计计入排名
├── 页面仅显示第一名金额（账号隐藏），用户登录后可见自己排名
└── 23:59:59 活动结束，停止统计

Day 2（4月19日）
├── 00:00 系统结算最终排名，确定Top3名单（用于顺延）
├── 08:00 权益正式生效（时段：08:00-24:00）
├── 活动页面公布获奖名单（显示账号名）
├── GM确认最终获胜者，单独拉群服务
└── 用户需要时联系GM调整数值

Day 3（4月20日）
├── 08:00-24:00 权益持续生效
├── GM根据获奖玩家需求进行属性维护
└── 24:00 权益到期，GM清除属性
```

## 四、奖励权益

### 4.1 权益内容（全服唯一，限时2天）

| 权益类型 | 效果 |
|----------|------|
| 体型增幅 | 所有恐龙体型增加 **50%** |
| 咬合力 | 所有恐龙咬合力 **+100点** |
| 专属称号 | 「Long Vương」（龙王） |

### 4.2 权益生效方式

- **生效时段：** 每日08:00-24:00（越南时间），共2天
- **服务方式：** GM单独拉群服务，用户需要时联系GM调整数值
- **服务人数：** 仅服务1名用户（单日充值冠军）
- **服务时段说明：** GM是否在08:00-24:00时段内值班，取决于小傅的GM自动化工具开发完成时间

### 4.3 权益失效条件

| 场景 | 处理结果 |
|------|----------|
| 生效时段内未上线 | 视作自动放弃该时段权益，不补偿 |
| 权益期内因不良行为被封号 | 玩家自行负责，不补偿 |
| 权益到期 | 自动失效，GM清除属性 |

## 七、规则要点汇总

1. **时间：** UTC+7，支付时间为准
2. **范围：** Q服+K服，账号级累计，仅官网充值
3. **排名：** 金额优先，同金额按时间先后
4. **榜单：** 仅显示第一名金额（隐藏账号）+ 自己排名（需登录）
5. **获奖：** 1名，第一名不可用则顺延，结束后公布账号
6. **权益：** 2天有效，每日08:00-24:00，GM拉群手动配置
7. **荣誉：** 本届为首任龙王，荣誉殿堂将在结果公布区展示
